# BMI Calculator (python)

A simple Python application to calculate **Body Mass Index (BMI)**.
This project includes both a **Command-Line Interface (CLI)** version and a **Graphical User Interface (GUI)** version built with Tkinter.

---

## Features

### CLI Version

-Prompts user for weight (kg) and height (m).
-Calculates BMI using the formula: BMI = Weight/(height**2)
-Classifies BMI into categories:
 -Underweight
 -Normal weight
 -Overweight
 -Obese
-Handles invalid inputs gracefully.

### GUI Version (Tkinter)

-User friendly window with input fields for weight and height.
-Displays BMI result and category in the interface.
-Error handling with popup messages.
-Clean and responsive design.

---

## How to Run

### Prerequisites

-Python 3.x installed on your system
-Tkinter (usually included with Python by default).

### Running the CLI Version

'''bash
python bmi_calculator_cli.py
